# KuroCat Workshop · 皮肤工坊 🐾

为桌面互动小猫 **[KuroCat](https://github.com/chanke17/KuroCat)** 打造的纯前端皮肤制作与配饰装扮工坊。  
无需安装依赖、无需后端服务器，打开网页就能用自家猫咪照片或钢笔工具做出专属的 `.kurocat` 皮肤，直接拖进 KuroCat「换装间」佩戴！

🌐 **在线体验（GitHub Pages）**：https://chanke17.github.io/KuroCat-Workshop/

---

## 功能亮点

- **📷 照片色块向量化生成**：上传真实猫咪照片，在浏览器本地直接做双边平滑 + 抗阴影 CIE Lab 聚类 + 轮廓追踪与贝塞尔曲线拟合，把自家猫的偏分刘海、白肚皮、三花斑块、瞳色等真实还原为可二次编辑的皮肤。
- **✒️ 钢笔画分区 & 对称镜像**：支持在脸部 / 头顶 / 身体 / 尾巴上画分割线、闭合色块或条纹笔触，支持左右对称联动镜像、随时拖锚点改弧度、支持 `Ctrl/⌘ + Z` 撤销重做。
- **🎀 18 款内置配饰 + 自定义贴纸上传**：
  - 内置头顶（皇冠、贝雷帽、礼帽、蝴蝶结、电竞耳机、小发芽、樱花、光环）、脸部（墨镜、金丝圆眼镜、腮红、创可贴）、颈部（红项圈金铃铛、小红围巾、红领结、领带）、尾尖（蝴蝶结、小星星）共 18 款装扮；
  - 支持上传任意 **PNG / WebP / JPG / SVG** 自定义贴纸，提供「自动去纯色底」抠图与透明边自动裁切，在 2.5D 小猫画布上可直接拖动、缩放、旋转。
- **🐱 实时 2.5D 互动预览**：与 KuroCat 原生 macOS / Windows / Linux 渲染器保持 100% 同步，支持鼠标转头追踪、待机/敲键盘/捕猎大眼/摸头闭眼/打瞌睡/三键踢脚等全动作预览。
- **📦 严格 `.kurocat` v1 规范导出**：内置规范校验与缩略图打包，导出的 `.kurocat` 文件可直接拖进 KuroCat「换装间」或拖到桌面小猫身上生效。

## 本地运行

项目为纯静态 HTML / CSS / JS，零构建步骤：

```bash
git clone https://github.com/chanke17/KuroCat-Workshop.git
cd KuroCat-Workshop
python3 -m http.server 8765
```

然后在浏览器打开 `http://127.0.0.1:8765/` 即可。

---

## 导入到 KuroCat

1. 点击右上角 **「导出 .kurocat」** 下载皮肤文件；
2. 在桌面右键小猫 → **「猫咪皮肤 🐱 → 导入皮肤…」** 打开 **「换装间」**，把 `.kurocat` 文件拖进去（或直接拖到桌面小猫身上）；
3. 导入的皮肤保存在系统用户数据目录（与软件本体分离），**KuroCat 后续版本更新会自动保留你上传的所有皮肤**，也可以在「猫咪皮肤 → 打开皮肤文件夹（备份）」中随时备份或分享给朋友。
